# 感覺器官小遊戲

樂華天主教小學科學課「感覺器官多重要」用的兩個網頁小遊戲。  
語言：繁體中文（香港），淺白字，適合小一、小二。不用登入，也不用安裝。

## 遊戲

1. **感官配對**（第1堂示範＋回家玩）  
   把眼睛、耳朵、鼻子、舌頭、皮膚配對功能。另有「牙齒｜咀嚼食物」：它很有用，但不是感覺器官。

2. **情境選感官**（第2堂示範＋回家玩）  
   看生活情境，先選用了哪些感覺器官（可多選），再選作用：保障安全、解決生活問題、認識事物的特性。共 10 題。

從首頁 `index.html` 進入。

## 怎樣打開

用 Chrome、Edge、Safari 或 Firefox 打開資料夾裡的 `index.html`（雙擊，或把檔案拖進瀏覽器）。手機和平板都可以玩。檔案都在本機，打開之後不必連網。

如果學校電腦不允許直接打開檔案，在這個資料夾執行：

```bash
python3 -m http.server 47321
```

然後打開 <http://127.0.0.1:47321/>。

## 三分鐘堂上示範

準備：教師電腦打開首頁，投到螢幕。同學可以用平板同時打開。

**0:00 首頁**  
說：「今日看感覺器官有多重要。我們有兩個遊戲。」  
指一指兩個大標題：感官配對、情境選感官。先玩第一個。

**0:30 感官配對**  
說：「點器官，再點功能。」  
示範：點「眼睛」，再點「看東西、辨顏色」。請全班讀「答對了」。  
再配一題：點「皮膚」，再點「感覺冷熱、軟硬等」。  
然後點「牙齒」，再按下面的「這不是感覺器官」（也可以把「牙齒」拖到任何一個功能上）。  
一起讀：「牙齒很有用，但不是感覺器官哦！」  
小結：感覺器官有五種——眼、耳、鼻、舌、皮膚。

**1:50 情境選感官**  
回到首頁，打開「情境選感官」。  
說：「先看情境，再選用了哪些感官，最後選作用。」  
第1題走廊轉角：點「耳朵」。如果有同學說到眼睛，可以加選「眼睛」。按「選好了」。  
再點「保障安全」，按「選好了」。  
一起讀星星和解釋。  
小結：感覺器官幫我們保障安全、解決生活問題、認識事物的特性。其餘題目可以回家玩完。

## 老師備忘：情境答案

可以多選的感官，只選必選那一個也算對。作用要選齊。

| 題 | 情境 | 感官 | 作用 |
| --- | --- | --- | --- |
| 1 | 走廊轉角，聽見急腳步聲，停低等人 | 耳（可加眼） | 保障安全 |
| 2 | 操場遠處老師吹哨，走回集合 | 耳 | 解決生活問題、保障安全 |
| 3 | 班房聞到異常焦味，告訴老師 | 鼻 | 保障安全 |
| 4 | 手背感到熱水壺熱氣，不碰壺身 | 皮膚 | 保障安全 |
| 5 | 飯堂看號碼牌，又聽廣播才入座 | 眼、耳 | 解決生活問題 |
| 6 | 圖書館用眼睛找書脊號碼 | 眼 | 解決生活問題、認識事物的特性 |
| 7 | 雨天樓梯，腳底覺得滑，扶欄慢慢行 | 皮膚（可加眼） | 保障安全 |
| 8 | 美術課摸紙，分辨粗糙或光滑 | 皮膚（可加眼） | 認識事物的特性 |
| 9 | 閉上眼睛，聽是拍手還是敲門 | 耳 | 認識事物的特性 |
| 10 | 嗅肥皂和濕毛巾 | 鼻 | 認識事物的特性 |
